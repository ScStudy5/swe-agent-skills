# Política de Seguridad (`SECURITY.md`)

## Versiones soportadas

| Versión | Soportada |
| :--- | :--- |
| `1.x` (actual) | Sí |
| `< 1.0` | No |

## Cómo reportar una vulnerabilidad

**Por favor, no reportes vulnerabilidades de seguridad a través de Issues públicos.**

Si descubres una falla de seguridad en este proyecto:

1. Envía un reporte privado a: `[security@tu-dominio.com]` (o mediante *GitHub Private Vulnerability Reporting*).
2. Incluye en la medida de lo posible:
   - Tipo de vulnerabilidad y componentes afectados.
   - Pasos reproducibles o prueba de concepto mínima (sin dañar datos reales).
   - Impacto estimado.

## Tiempos objetivo de respuesta
- **Acuse de recibo:** dentro de `[48 horas]`.
- **Evaluación inicial y severidad:** dentro de `[5 días hábiles]`.
- **Mitigación / parche:** según criticidad (Crítica prioritaria, rotación de credenciales si hubo exposición).

## Alcance de pruebas autorizadas
- Solo se autorizan pruebas sobre entornos de desarrollo/pruebas designados o bajo acuerdos explícitos.
- Prohibido exfiltrar datos reales de usuarios o provocar denegación de servicio en producción.
